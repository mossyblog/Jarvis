## Additional Variables

### Sidebar Colors
Both themes include sidebar-specific colors that follow the same pattern:
- `--sidebar-background`
- `--sidebar-foreground`
- `--sidebar-primary`
- `--sidebar-primary-foreground`
- `--sidebar-accent`
- `--sidebar-accent-foreground`
- `--sidebar-border`
- `--sidebar-ring`

### Extended Color Palette
The Supabase theme includes additional gray scale colors:
- `--gray-100` through `--gray-900`
- `--brand` and `--brand-600`
- `--dash-sidebar`
- `--default`

### Helper Colors
- `--foreground-light`
- `--foreground-lighter`
- `--border-stronger`

## Notes for tweakcn

1. The color format is HSL with space-separated values (e.g., `142 75% 57%`)
2. All themes support both light and dark modes
3. The Supabase theme uses a green accent color (#3fcf8e in dark mode)
4. The default theme uses a more neutral color scheme
5. Border radius is consistent across all themes: `--radius: 0.5rem`
